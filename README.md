# Red Drift: Earth to Mars 🚀🪐

A fast-paced, side-scrolling 2D space shooter written in **C++17** and **modern OpenGL 3.3**. Pilot your cruiser from Earth to Mars, dodge asteroid fields, fight enemy ships, and spend your hard-earned Sol on upgrades in the workshop.

## 🎨 Pure Procedural Graphics

Everything on screen (ships, planets, space stations, explosions, menus and even the font) is **drawn from triangles by our own C++ code**.

* **No external textures, 3D models or font files** are loaded from disk.
* All visuals rely on our vertex/fragment shaders, procedural geometry and alpha blending.

## ⚙️ Quick Start

### Prerequisites

* **CMake** 3.16 or higher
* A **C++17** compiler (Visual Studio 2022, GCC or Clang)
* A GPU driver that supports **OpenGL 3.3 Core**

> GLFW, GLEW and GLM are already bundled in `vendor/`, so there is nothing extra to download.

### Build and Run

**Windows (Visual Studio)**

```powershell
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build --config Release
.\build\Release\RedDrift.exe
```

**Linux**

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/RedDrift
```

## 🎮 How to Play and Controls

| Action | Key / Input | Description |
| --- | --- | --- |
| **Move** | `WASD` or arrow keys | Fly the cruiser inside the flight corridor. |
| **Pulse fire** | `Space` or left click | Fire standard bullets. |
| **Continuous laser** | Right mouse button (hold) | Heavy beam weapon *(buy it in the workshop)*. |
| **Homing missiles** | `E` (hold) | Lock on to a target and launch missiles *(buy them in the workshop)*. |
| **Boost** | `Shift` | Speed up using the shared energy reserve. |
| **Pause** | `P` | Pause or resume the mission. |
| **Retry** | `R` | Restart the current stage. |
| **Menu / Back** | `M` or `Esc` | Return to level select (`Esc` in the menu exits). |
| **Fullscreen** | `F11` | Toggle windowed and fullscreen mode. |
| **Level select** | `1`-`6`, mouse, `Enter` | Choose and start a stage. |
| **Workshop** | `W`, `Tab` or arrows, `1`-`2` | Open the upgrade workshop and buy upgrades. |

## 🚀 Game Features

* **6 stages:** from the Earth stratosphere past the Moon and through deep space to Mars, with a launch cutscene, a Moon landing and take-off, and a Mars finale.
* **Economy and upgrades:** earn **Sol** by destroying enemies (25 for a light ship, 60 for a heavy one). After your first landing at the Moon station, the workshop unlocks. Upgrade hull and energy (up to 225), and buy the laser and homing missiles (levels 1-5).
* **Automatic saves:** Sol, weapons and completed stages are stored in a small versioned file (`%LOCALAPPDATA%\RedDrift\progress.txt` on Windows).
* **Automated tests:** four CTest programs check flight, workshop and weapons, the Mars finale and weapon upgrades.

```powershell
ctest --test-dir build -C Release --output-on-failure
```

The renderer is 2D, so there is no 3D camera, lighting or depth testing. The report explains the pipeline, the math and these limits in detail.

## 📂 Code Map

* `src/main.cpp`: window, input, main loop and smoke-test modes.
* `src/Level.*`, `src/LevelWeapons.cpp`: game rules, enemy waves, collisions and weapons.
* `src/Player.*`, `src/Progress.*`: ship movement, energy and saved upgrades.
* `src/Renderer*.cpp`: procedural ships, scenes, effects and UI.
* `shaders/`: GLSL 330 vertex and fragment shaders.
* `tests/`: automated tests.
